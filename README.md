# Электронная библиотека

Автоматизированная информационная система (АИС) «Электронная библиотека», разработанная в рамках экзаменационного проекта. 
Включает в себя функции ведения реестра книг, загрузки обложек, добавления рецензий и подробную статистику (Вариант №4).

## Учётные данные для тестирования

База данных уже заполнена тестовыми книгами, жанрами и обложками. В системе предусмотрены 3 уровня доступа (роли). 

**1. Администратор** (Имеет полный доступ, включая удаление книг, добавление новых книг и просмотр вкладки "Статистика"):
* **Логин:** `admin`
* **Пароль:** `admin`

**2. Модератор** (Может редактировать существующие книги и писать рецензии):
* **Логин:** `moderator`
* **Пароль:** `moderator`

**3. Пользователь** (Обычный читатель, может только просматривать книги и писать рецензии):
* **Логин:** `user`
* **Пароль:** `user`

## Локальный запуск проекта

Проект использует легковесную встроенную базу данных `SQLite`, поэтому установка дополнительных СУБД (вроде MySQL) не требуется. База данных уже лежит в папке `instance/library.db` с готовыми данными.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DanilaKuznetsov/web-develop-exam.git
   cd web-develop-exam
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   
   # Для Windows:
   venv\Scripts\activate
   
   # Для Mac/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите локальный веб-сервер:
   ```bash
   python run.py
   ```

5. Откройте браузер по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)
